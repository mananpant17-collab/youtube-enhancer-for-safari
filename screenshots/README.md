# Screenshots

Put the images used by the main README in this folder. Suggested set:

| File name | What to capture |
|---|---|
| `player-with-control-bar.png` | A YouTube watch page showing the control bar under the video. |
| `speed-indicator.png` | The speed label (for example "1.75x") over the player while pinching. |
| `settings-page.png` | The full options page (Safari > Settings > Extensions > the extension > Settings). |
| `toolbar-popup.png` | The toolbar popup with its quick on/off toggles. |
| `hide-shorts.png` (optional) | A before/after of a YouTube page with Hide Shorts on. |

Tips:

- Use PNG. Keep each image under about 1 MB (the README looks better and loads faster).
- Crop out your bookmarks, other extensions, tab titles, and anything personal.
- Then replace the placeholder line in the main `README.md` with, for example:
  `![Control bar under the player](screenshots/player-with-control-bar.png)`
